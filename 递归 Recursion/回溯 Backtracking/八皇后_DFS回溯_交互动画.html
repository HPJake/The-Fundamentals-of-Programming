代码执行到哪里了？

下面是和动画一一对应的 C++ 核心逻辑，绿色高亮代表当前步骤。

1 void dfs(int col) {
2 if (col == n + 1) {
3 recordAnswer(); return;
4 }
5 for (int row = 1; row <= n; row++) {
6 if (conflict(row, col)) continue;
7 placeQueen(row, col); // 标记
8 dfs(col + 1); // 深入
9 removeQueen(row, col);// 回溯
10 }
11}
01 · 决策

每层递归只管一列

dfs(col) 的意思是：前面的列已处理，现在要给第 col 列找一个合法行。这样天然不会出现同列冲突。

02 · 约束

同行、同斜线都不行

同行皇后不能共存；同一条 \ 斜线的 行－列 相等；同一条 / 斜线的 行＋列 相等。

03 · 恢复

谁修改状态，谁恢复

当前层放下皇后并标记占用；子递归全部探索完后，当前层撤销自己的标记，才能换个位置继续试。

你刚才最关心的问题：为什么回溯不需要加「失败了才撤销」的条件？

因为本题要求找出 所有 方案，而不是找到一种就停。只要当前位置合法且已经执行过 放置 → dfs(col + 1)，当子递归返回时，就一定要执行 撤销。返回表示这个分支已经探索完毕，并不等于这个分支失败了。 点击上方「跳到下一次回溯」，观察皇后和占用标记如何恢复。
