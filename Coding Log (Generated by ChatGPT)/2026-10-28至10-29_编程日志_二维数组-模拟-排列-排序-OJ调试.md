## 1. 本次知识地图和高频错误

| 现象 / 原写法 | 根本原因 | 修正 / 记忆点 |
|---|---|---|
| `cout << p;`（`pair<int,int>`） | 标准库没有默认的 `pair` 输出运算符 | `cout << p.first << ' ' << p.second;` |
| 二维大数组局部定义导致程序打不开或闪退 | 可能栈内存不足；**不能仅凭症状确定** | 全局数组，或读入时直接统计而不保存 |
| 扫描矩阵时不断给 `LU/RL` 赋值 | 记录的是**最后一个**匹配位置，不是第一个 | 维护 `minRow/minCol/maxRow/maxCol` |
| `return 0` 用于跳出循环 | 会退出整个 `main()`，后面代码不执行 | 只退一层用 `break`；多层循环用标记 |
| 最大全 0 矩形遇到树仍继续增加宽度 | 矩形不能跨过有树的列 | `valid[j]=false`；遇到非法列 `width=0` |
| 山顶检测用 `>=` 排除相等邻居 | 题意允许相等高度 | 只有发现邻居 **严格更高** 才否定山顶 |
| 矩阵周围直接补 0 | 高度可能为负，外侧的 0 会改变比较结果 | 对局部最大值补 `INT_MIN`，或显式判边界 |
| `vector<vector<int>> v[10001]` 后 `v[i].push_back(x)` | 容器层数过多，`v[i]` 需要 `vector<int>` | `vector<int> v[10001]` 或 `vector<vector<int>> v(N)` |
| `push_back(x)`，但只声明了 `b` | `x` 未定义 | `push_back(b)` |
| `unique()` 后误以为长度缩短 | `unique` 只移动元素并返回新逻辑终点 | `v.erase(unique(...),v.end())` |
| `sort(v.begin(),v.end())` 对 `pair` 排序 | 默认先排 `first`、再排 `second` | 如果只看 `first` 且同键稳定，使用比较函数+`stable_sort` |
| 函数参数直接写 `auto` 编译警告 | 普通函数 `auto` 形参需要 C++20 | C++11 写完整类型；泛型 lambda 是 C++14 |
| OJ 报 `Wrong Answer` | 可能仅仅多一个空格，也可能是算法错误 | 使用与题目**逐字符一致**的格式 |
| OJ 报 `Empty output file: '3.out'` | 无法仅凭提示确认是程序问题还是评测环境问题 | 做最小输出实验、查退出状态、询问助教；不推定已 AC |

## 2. `pair` 的输出与排序

### 2.1 为什么不能直接 `cout << pair`？

```cpp
#include <iostream>
#include <utility>
using namespace std;

int main() {
    pair<int, int> p = {3, 5};

    // cout << p; // 编译错误：标准库没有直接输出 pair 的 operator<<
    cout << '(' << p.first << ", " << p.second << ')' << endl;
    return 0;
}
```

输出：`(3, 5)`。`pair` 的两个值分别通过 `.first` 与 `.second` 访问。`vector<pair<int,int>>` 可以用范围 for 遍历，但输出时仍须分开取值。

### 2.2 按 `pair.first` 排序

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 仅按 first 升序比较：适用于只关心第一项的排序
bool cmp(const pair<int, int>& a, const pair<int, int>& b) {
    return a.first < b.first;
}

int main() {
    vector<pair<int, int>> v = {{3, 20}, {1, 8}, {3, 10}, {2, 9}};

    // 默认排序：先按 first 升序，first 相等时按 second 升序
    sort(v.begin(), v.end());

    // 如果想相同 first 时保持原输入顺序，使用：
    // stable_sort(v.begin(), v.end(), cmp);

    for (const auto& p : v) {
        cout << p.first << ' ' << p.second << '\n';
    }
    return 0;
}
```

> **考试提醒：** `sort(v.begin(),v.end())` 对 `pair` 默认执行**字典序比较**，不等于“只比较 `first`”。另外 `stable_sort` 的稳定性要搭配**只比较 `first`** 的比较函数，才表示相同 `first` 的输入顺序保持不变。

## 3. 二维数组：寻找零区域的两个角

### 3.1 当时的写法为何不可靠？

```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (a[i][j] == 0) {
            LU.first = i; // 每遇到 0 都覆盖 LU
            LU.second = j;
        }
    }
}
```

这不表示“找到了左上角”，而是**一直覆盖成最后一个 0**。逆向扫描后不断覆盖 `RL`，也会出现类似问题。

另有 `int a[1001][1001];` 放在 `main()` 内的问题：若 `int` 为 4 字节，数组约占 4 MB 栈空间，**某些**编译环境可能栈溢出。但“无法执行”不一定只有这一种原因，要看报错与运行表现。

### 3.2 更适合的算法：读入时直接更新四个极值

假设题目要找的是所有 `0` 的**最小包围矩形**，无需保存整个矩阵：

```cpp
#include <iostream>
#include <algorithm> // min、max
using namespace std;

int main() {
    int n;
    cin >> n;

    // 分别记录所有 0 所在位置的最小/最大行号与列号
    int minRow = n, minCol = n;
    int maxRow = -1, maxCol = -1;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            int x;
            cin >> x; // 只读当前值，不需要存到二维数组中

            if (x == 0) {
                minRow = min(minRow, i);
                minCol = min(minCol, j);
                maxRow = max(maxRow, i);
                maxCol = max(maxCol, j);
            }
        }
    }

    if (maxRow != -1) { // 有 0 才可以输出有效坐标
        cout << minRow << ' ' << minCol << ' '
             << maxRow << ' ' << maxCol << '\n';
    }
    return 0;
}
```

- **时间复杂度：** `O(n²)`（所有输入都要读取）。
- **额外空间：** `O(1)`。
- **注意：** 题目若要求 1 开始编号，输出需相应 `+1`；若不是找所有 0 的包围矩形，也不能未经题意确认就套用此方法。

## 4. `break`、`continue`、`return` 与多层循环

| 语句 | 执行结果 |
|---|---|
| `break;` | 跳出**最近一层**循环或 `switch` |
| `continue;` | 跳过本轮剩余部分，进入下一轮循环 |
| `return 0;`（在 `main` 中） | 直接结束整个程序的 `main` 函数 |
| `return x;`（其他返回值函数中） | 结束函数，并把 `x` 传回调用方 |

```cpp
bool found = false;

// 寻找第一个满足条件的坐标：找到后退出两层循环
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (a[i][j] == 0) {
            cout << i << ' ' << j << '\n';
            found = true; // 给外层循环传递“已找到”的信号
            break;        // 仅跳出内层 j 循环
        }
    }
    if (found) break;      // 再跳出外层 i 循环
}

// 此处的代码仍会执行；如果改成 return 0 则不会
```

**注意：** 如果有后续必须执行的代码（例如统计结果再输出），不能随便用 `return 0` 代替 `break`。

## 5. 护林员盖房子：最大全 0 矩形

### 5.1 题目模型

- 输入：`m × n` 的 0/1 矩阵（`m,n ≤ 20`）。
- `1` 是树木，`0` 是空地。
- 求只含 `0` 的**最大轴对齐矩形面积**。
- **一行高或一列宽的矩形也合法**；样例中一整行 5 个 `0`，答案为 `5`。

### 5.2 核心思想：枚举上下边界，将二维变一维

固定上边界 `top` 和下边界 `bottom`，判断每一列在这几行中是否全为 0：

```text
valid[j] = true  ：第 j 列在 top～bottom 的每一行都是 0
valid[j] = false ：至少有一个 1，该列不能加入当前矩形
```

然后从左到右找最长连续合法列：

```cpp
if (valid[j]) width++;
else width = 0; // 不能跨越有树的列
```

面积 = `width * (bottom - top + 1)`。

### 5.3 完整可复习代码（C++11）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int m, n; // m 行，n 列
    cin >> m >> n;

    int a[25][25];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            cin >> a[i][j]; // 0：空地；1：树木
        }
    }

    int ans = 0; // 目前找到的最大面积

    // 第一层：枚举矩形的上边界
    for (int top = 0; top < m; top++) {
        bool valid[25];

        // 重新选定 top 后，先假设每一列都合法
        for (int j = 0; j < n; j++) valid[j] = true;

        // 第二层：让下边界逐行向下延伸
        for (int bottom = top; bottom < m; bottom++) {
            int width = 0; // 当前连续“全 0 列”的数量

            // 第三层：从左到右检查每一列
            for (int j = 0; j < n; j++) {
                // 新加入的 bottom 行若有树，则此列永久失效
                // （对当前固定的 top 而言）
                if (a[bottom][j] == 1) valid[j] = false;

                if (valid[j]) width++; // 连续合法列增加
                else width = 0;        // 遇到树，中断连续区间

                int height = bottom - top + 1;
                ans = max(ans, width * height);
            }
        }
    }

    cout << ans << '\n';
    return 0;
}
```

**复杂度：** 枚举 `top`、`bottom` 有 `O(m²)` 种，逐列扫描 `O(n)`；总 `O(m²n)`，额外辅助空间 `O(n)`。

> **误区：** `valid[j]` **不用**在每次 `bottom` 改变时重置，否则会忘记上面几行存在的树。只有换新的 `top` 时才全部重置。

## 6. 计算鞍点：行最大、列最小

### 6.1 定义与样例

鞍点必须同时满足：

1. 是所在**行的最大值**；
2. 是所在**列的最小值**。

例题的 `5×5` 矩阵中，第 4 行第 1 列的 `8` 同时满足这两点，因此输出 `4 1 8`（**题目坐标从 1 开始**）。

### 6.2 最直观算法

每行先找最大值所在列 `max_j`，再沿这列扫描，检查有没有比当前候选元素更小的值。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5][5];
    for (int i = 0; i < 5; i++) {
        for (int j = 0; j < 5; j++) cin >> a[i][j];
    }

    for (int i = 0; i < 5; i++) {
        int max_j = 0; // 记录下标，而非只记录最大值

        // 在第 i 行找最大值的列
        for (int j = 1; j < 5; j++) {
            if (a[i][j] > a[i][max_j]) max_j = j;
        }

        bool isSaddle = true; // 先假设满足列最小条件
        for (int k = 0; k < 5; k++) {
            // 只要存在更小的同列元素，就不是鞍点
            if (a[k][max_j] < a[i][max_j]) {
                isSaddle = false;
                break;
            }
        }

        if (isSaddle) {
            // 题目行列编号从 1 开始，所以各 +1
            cout << i + 1 << ' ' << max_j + 1 << ' '
                 << a[i][max_j] << '\n';
            return 0; // 找到并输出后，结束 main
        }
    }

    cout << "not found\n";
    return 0;
}
```

**适用前提：** 题目保证每行最大值、每列最小值具有唯一性；若不保证，可能需要考虑同一行的多个最大值。

## 7. 山顶：方向数组、边界与哨兵

### 7.1 题目定义

一个位置是山顶，当且仅当它**不低于**上下左右所有**存在的**相邻位置。相等不妨碍成为山顶。题目输出的坐标为**0 开始**，且按行、再按列升序输出。

因此“邻居严格高于当前值”才会否定山顶：

```cpp
if (a[nx][ny] > a[i][j]) isPeak = false;
```

### 7.2 `dx` 和 `dy` 负责什么？

```cpp
// (dx[d],dy[d]) 是一次移动时的“行变化、列变化”
int dx[4] = {-1, 1, 0, 0};
int dy[4] = { 0, 0,-1, 1};
//             上 下 左 右
```

```cpp
int nx = i + dx[d];
int ny = j + dy[d];
```

它们解决的是**如何枚举四个方向**，不是越界问题。

### 7.3 哨兵边界（Padding）负责什么？

如果把原矩阵存在 `a[1..m][1..n]`，并额外保留第 0 行/列与第 `m+1` 行、第 `n+1` 列，那么访问 `a[i±1][j]`、`a[i][j±1]` 就不会越界。

**为什么不能无条件填 0？** 如果真实高度可能为负数，比如 `-5`，边界的 `0` 会被错误当作更高的邻居。寻找局部最大值时更稳妥的哨兵是 `INT_MIN`。

### 7.4 `dx/dy + 哨兵` 完整版本

```cpp
#include <iostream>
#include <climits> // INT_MIN
using namespace std;

int main() {
    int m, n;
    cin >> m >> n;

    int a[25][25]; // 题目 m,n <= 20，预留外围一圈

    // 先把所有位置填为极小值，作为四周的哨兵
    for (int i = 0; i < 25; i++) {
        for (int j = 0; j < 25; j++) a[i][j] = INT_MIN;
    }

    // 实际数据从 (1,1) 开始保存
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) cin >> a[i][j];
    }

    int dx[4] = {-1, 1, 0, 0}; // 上、下、左、右
    int dy[4] = { 0, 0,-1, 1};

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            bool isPeak = true;

            for (int d = 0; d < 4; d++) {
                int nx = i + dx[d];
                int ny = j + dy[d];

                // 有哨兵保护，访问四周不会越界
                // 只有真正更高的邻居才取消山顶资格
                if (a[nx][ny] > a[i][j]) {
                    isPeak = false;
                    break;
                }
            }

            // 输出下标须 -1，恢复为题目要求的 0 起点
            if (isPeak) cout << i - 1 << ' ' << j - 1 << '\n';
        }
    }
    return 0;
}
```

**两个技巧可以独立使用：**

- `dx/dy`：省去四份几乎重复的相邻位置检查代码。
- 哨兵：省去每次相邻位置访问前的越界判断。

也可以不使用方向数组，直接比较 `a[i-1][j]`、`a[i+1][j]`、`a[i][j-1]`、`a[i][j+1]`，本质相同。

## 8. `vector` 容器层数与 `push_back` 编译错误

### 8.1 当时的错误代码

```cpp
vector<vector<int>> v[10001];
// ...
v[i].push_back(a); // 编译错误：v[i] 的元素应是 vector<int>
// ...
int b; cin >> b;
v[i].push_back(x); // 编译错误：变量 x 没有声明
```

**类型逐层拆开看：**

| 定义 | `v` 整体 | `v[i]` | `v[i][j]` |
|---|---|---|---|
| `vector<int> v[10001]` | vector 的数组 | `vector<int>` | `int` |
| `vector<vector<int>> v(N)` | 二维 vector | `vector<int>` | `int` |
| `vector<vector<int>> v[10001]` | 二维 vector 的数组 | `vector<vector<int>>` | `vector<int>` |

所以若需要第 `i` 组装若干整数，应该定义：

```cpp
vector<vector<int>> v(N);
v[i].push_back(a);
v[i].push_back(b);
```

### 8.2 逻辑错误：找到匹配编号却保存错了值

如果约定 `v[i][0]` 是**组编号 a**、后面 `v[i][1..]` 是关联编号 `b`，那么：

```cpp
if (v[i][j] == max_i) {
    ment.push_back(v[i][0]); // 保存组编号 a
    break;                    // 当前组已经满足，防止重复收集
}
```

不是 `ment.push_back(v[i][j]);`，后者会把匹配的 `max_i` 本身再次加入。

**其他易错点：**

- `int max_i;` 如果从未更新就会使用未初始化变量，应给有效初值。
- `user[101]` 下标最多 100，**只有题目保证编号在 0～100 时才够用**。
- 如果需要输出编号去重，确认每组是否可能重复，并且考虑 `unique()`。
- `sort(ment.begin(),ment.end())` 会改变收集顺序，务必核对题目要求。

## 9. `vector` 去重：`sort + unique + erase`

### 9.1 经典模板

```cpp
#include <vector>
#include <algorithm>
using namespace std;

vector<int> v = {3, 1, 2, 3, 2, 1, 4};

sort(v.begin(), v.end());
// v: 1 1 2 2 3 3 4

// unique 只把“每段相邻相等的元素”压缩到前面，
// 返回新有效范围的尾后迭代器，不真正改变 v.size()
v.erase(unique(v.begin(), v.end()), v.end());
// v: 1 2 3 4
```

### 9.2 为什么必须先排序？

`unique()` 只处理**相邻重复**。例如 `{1,2,1}`，直接 `unique` 无法把隔开的两个 `1` 合并。若希望整个数组去重并从小到大排列，应先 `sort()`。

### 9.3 如果需要保留原顺序

```cpp
vector<int> result;
for (int x : v) {
    // 若 result 里还没有 x，就加入
    if (find(result.begin(), result.end(), x) == result.end()) {
        result.push_back(x);
    }
}
```

这是易懂的 `O(n²)` 方法，适合数据规模不大。注意 `v.erase(remove(...),v.end())` 是**删除某个具体值**，和 `unique()` 去重不是同一回事。

## 10. 跳水比赛：枚举全排列

### 10.1 模型

用 `a[0..4]` 表示 A、B、C、D、E 的名次。名次为 `1..5` 且不能重复，所以全部可能只有 `5! = 120` 种；直接枚举即可。

题干给出每人两句预测，且**恰好一真一假**：

| 人 | 预测① | 预测② |
|---|---|---|
| A | B 第二 | A 第三 |
| B | B 第二 | E 第四 |
| C | C 第一 | D 第二 |
| D | C 第五 | D 第三 |
| E | E 第四 | A 第一 |

### 10.2 完整代码（逐条对应题意）

```cpp
#include <iostream>
#include <algorithm> // next_permutation
using namespace std;

int main() {
    // 每个下标对应一位选手：0=A, 1=B, 2=C, 3=D, 4=E
    // 值是这位选手的名次，排列天然保证名次不同
    int a[5] = {1, 2, 3, 4, 5};

    do {
        // 两个布尔条件相加等于 1，代表恰好一句为真
        bool Aok = ((a[1] == 2) + (a[0] == 3) == 1);
        bool Bok = ((a[1] == 2) + (a[4] == 4) == 1);
        bool Cok = ((a[2] == 1) + (a[3] == 2) == 1);
        bool Dok = ((a[2] == 5) + (a[3] == 3) == 1);
        bool Eok = ((a[4] == 4) + (a[0] == 1) == 1);

        if (Aok && Bok && Cok && Dok && Eok) {
            for (int i = 0; i < 5; i++) cout << a[i] << '\n';
            return 0; // 找到符合题干五组条件的排列
        }
    } while (next_permutation(a, a + 5));

    return 0;
}
```

**核对提醒（很重要）：** 依照聊天中读到的**文字条件**，这组条件对应结果 `3,1,5,2,4`；但截图中的**样例输出**却显示 `1,2,3,4,5`，二者不一致。不能在没有进一步核对原题前把上述代码标记为“已被该 OJ 接受”。这也是读题时要留意的来源冲突。

## 11. `next_permutation()` 系统复习

### 11.1 定义

```cpp
#include <algorithm>
next_permutation(a, a + n);
```

它把序列**原地修改**为按字典序紧接着的下一个排列；**返回 `bool`，不是返回排列**：

- `true`：确实存在更大的下一个排列。
- `false`：已经是最后一个排列，并把序列重排为字典序最小顺序。

### 11.2 枚举所有排列的标准写法

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a[3] = {3, 1, 2};

    // 必须先升序排列，才不会漏掉比初始排列小的那些结果
    sort(a, a + 3);

    do {
        // do...while 能处理初始排列，避免漏掉第一种情况
        for (int i = 0; i < 3; i++) cout << a[i] << ' ';
        cout << '\n';
    } while (next_permutation(a, a + 3));

    return 0;
}
```

排列次序：`123 → 132 → 213 → 231 → 312 → 321`。

### 11.3 底层原理（理解即可）

从右向左找到首个 `a[i] < a[i+1]` 的位置（枢轴），把它与右侧**刚好更大**的元素交换，再反转右侧后缀，使后缀尽可能小。

示例：`1 3 5 4 2 → 1 4 2 3 5`。

### 11.4 常见误区

- **不是随机交换，也不是每次生成全部排列。**
- `while (next_permutation(...))` 会先换排列，容易漏掉初始排列；用 `do...while`。
- 最好 `sort()` 后再开始枚举。
- 允许重复值，例如 `1,1,2`，只产生 `112、121、211` 三种不同排列。
- 单次 `O(n)`，枚举全部排列的规模随 `n!` 激增；5 个元素合适，20 个通常不合适。

## 12. 众数和中位数：输入、规则与输出格式

### 12.1 题目规则要完全照抄

- 输入第一行是序列个数 `T`，之后每行一个由**逗号分隔的无符号整数序列**；每行最多 500 个数，数值不大于 150。
- 众数：出现频率最高者；若并列，取**原序列中最先出现**的数。
- 如果**所有数字均相同**，众数用 `NO` 表示。
- 中位数：排序后取中间元素；偶数个时输出**表达式** `(x1+x2)/2`，不能把它直接化简成小数或整数。
- 输出格式：**`mode=...,median=...`，逗号后没有空格**。

### 12.2 题目样例的正确输出

输入：

```text
3
6,2,4,2,3,3
1,2,4,2,5,3,6
2,2,2,2,2,2,2
```

输出：

```text
mode=2,median=(3+3)/2
mode=2,median=3
mode=NO,median=2
```

### 12.3 一份便于复习的 C++11 参考实现

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int T;
    cin >> T;

    string line;
    getline(cin, line); // 清除 T 后面的换行

    for (int t = 0; t < T; t++) {
        // 每个序列占一行，且题目按正常输入保证序列非空
        if (!getline(cin, line)) break;

        // 逗号转空格，避免用 stoi 处理每个小段
        for (char &c : line) {
            if (c == ',') c = ' ';
        }

        stringstream ss(line);
        vector<int> v;
        int freq[151] = {0};
        int x;

        while (ss >> x) {
            v.push_back(x);
            // 仅在题目给出的 0～150 非负范围内使用此数组
            freq[x]++;
        }

        if (v.empty()) {
            // 如果评测数据允许空行，需根据题目具体约定处理；
            // 本题示例与文字没有定义空序列该怎样输出。
            continue;
        }

        // 先在原输入顺序下决定众数，避免丢失“先出现者”规则
        int mode = v[0];
        for (int x : v) {
            if (freq[x] > freq[mode]) mode = x;
        }

        // 若有数字的频率等于序列长度，说明全部相同
        if (freq[mode] == (int)v.size()) cout << "mode=NO";
        else cout << "mode=" << mode;

        cout << ",median="; // OJ 比对中出现过此处多空格的问题

        sort(v.begin(), v.end());
        int n = (int)v.size();

        if (n % 2 == 1) {
            cout << v[n / 2];
        } else {
            cout << '(' << v[n / 2 - 1] << '+'
                 << v[n / 2] << ")/2";
        }
        cout << '\n';
    }
    return 0;
}
```

> **运行状态：** 这是可供学习和本地测试的参考实现；对这道题，历史上有连续数次 OJ `Empty Output`，**不能据此宣称已经通过隐藏测试**。

## 13. 北大 OJ：Wrong Answer 与 Empty Output

### 13.1 最早的 Wrong Answer 证据

OJ 的首处差异显示：

```text
Std: mode=2,median=(3+4)/2
Out: mode=2, median=(3+4)/2
```

多的正是 `,` 后面的**一个空格**。这种情况改输出语句即可：

```cpp
cout << "mode=" << mode << ",median=";
```

但是 OJ 只显示了**第一处差异**，不能由此认定整份程序除此之外绝无错误。

### 13.2 后续连续遇到的 Empty Output

截图显示：

```text
Case 0: Diff = 0
Case 1: Diff = 0
Case 2: Diff = 1
Empty output file: '3.out'
```

**这条报错不足以区分：**

1. 程序因空输入、错误处理、异常或提前 `return` 导致未输出；
2. OJ 的某个评测文件、输出文件生成或比较流程异常。

特别提醒：`3.out` 是提示中的文件名，**不能在不知道平台具体机制时直接断言它就是用户程序的标准输出文件**。

### 13.3 比反复重写更有效的排查步骤

1. **保存最早能够输出结果的版本**，只修正已经证实的格式差异，重新测试。
2. 用两三组有代表性的本地数据测试：并列众数、全等、奇数/偶数长度、最大值 150、长序列。
3. 用能稳定输出常量的极简程序进行**诊断实验**，观察相同测试点是否仍被判成“空输出”。这是诊断，不是正式解答。
4. 如不同代码、不同同学都在同一测试点遇到相同异常，可收集截图反馈助教。
5. 未查到 OJ 官方故障公告、未得到助教确认时，只能说**存在平台问题的可能**，不能断言已经确定是 OJ 错误。

**经验教训：** 不要把“能够正常编译”“本地样例正确”“OJ AC”混为一谈；也不要把评测系统的异常提示过早归因于某一方。

## 14. `auto` 参数与 C++ 标准版本

当时的警告：

```text
[Warning] use of 'auto' in parameter declaration only available with -std=c++1y or -std=gnu++1y
```

按**真实语法**区分：

| 写法 | 从哪个 C++ 标准开始合法 |
|---|---|
| `auto x = 10;` | C++11 |
| `for (auto x : v)` | C++11 |
| `[](auto a, auto b) { ... }`（泛型 lambda） | C++14 |
| `bool cmp(auto a, auto b) { ... }`（普通函数） | C++20 |

因此 C++11 / 老版本 OJ 最稳妥的是把类型写全：

```cpp
bool cmp(const pair<int, int>& a, const pair<int, int>& b) {
    return a.first < b.first;
}
```

注意：不同编译器对非标准语法可能给予警告而不是立刻拒绝，**能编译不等于符合指定的 C++ 标准**。
