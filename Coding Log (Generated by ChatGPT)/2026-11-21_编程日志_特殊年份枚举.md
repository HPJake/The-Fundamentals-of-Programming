## 二、问题记录：特殊的年份

### 1. 今天的提问和题意

- 用户：**「我们今天复盘一道简单的题吧」**。
- 选定题目：「特殊的年份」。在四位年份 `year` 之后，找出**严格大于**它、且四个数位**两两不同**的最小年份。
- 用户随后要求：**「你写出完整代码」**。

例子：`1987` 后的第一个满足条件的年份是 `2013`；`3102` 后的是 `3104`。

### 2. 主要算法思路

1. 从 `year + 1` 起，逐年向后枚举，最多检查到 `9999`。
2. 将每个候选年份拆成千、百、十、个位四个整数。
3. 用六个不等式检查四个数字是否两两不同。
4. 一旦找到第一个满足条件的年份，立即输出并 `break`。由于枚举顺序递增，第一个符合条件的年份就是最小答案。

**数位分离示例（以 `i = 2026` 为例）：**

| 数位 | C++ 表达式 | 得到的数字 |
| --- | --- | ---: |
| 千位 | `i / 1000` | 2 |
| 百位 | `i / 100 % 10` | 0 |
| 十位 | `i / 10 % 10` | 2 |
| 个位 | `i % 10` | 6 |

注意：上述表达式使用**整数运算**；整数除法会截去小数部分。

### 3. 当天给出的完整 C++ 解法

以下代码按照当天对话使用的输入形式：先读入测试数据组数 `n`，再依次读入各组起始年份。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;  // 测试数据组数

    while (n--) {
        int year;
        cin >> year;

        for (int i = year + 1; i <= 9999; i++) {
            int a = i / 1000;       // 千位
            int b = i / 100 % 10;   // 百位
            int c = i / 10 % 10;    // 十位
            int d = i % 10;        // 个位

            if (a != b && a != c && a != d &&
                b != c && b != d &&
                c != d) {
                cout << i << '\n';
                break;
            }
        }
    }

    return 0;
}
```

**当天讨论中的样例：**

输入：

```text
2
1987
3102
```

输出：

```text
2013
3104
```

**复杂度：** 每组测试数据至多考察约一万个候选年份，每个年份进行固定次数的数位提取和比较。因此时间复杂度为 `O(9999 - year)`（粗略上界 `O(10^4)`），额外空间复杂度为 `O(1)`。

### 4. 报错、错误写法及修正情况

**今天可获取的这道题对话中，没有用户提交的错误代码、编译报错或判题失败记录。** 因此不能把以下易错写法说成用户真的犯过的错误；它们仅作为复盘提醒。

| 典型易错写法 | 为什么不对 | 正确写法 |
| --- | --- | --- |
| `for (int i = year; ...)` | 会把原年份本身也纳入检查，违反“严格大于” | `for (int i = year + 1; ...)` |
| `int b = i / 100;` | 得到的是前两位组成的数（如 20），不是百位数字 | `int b = i / 100 % 10;` |
| 只比较相邻的三组数字 | 不能排除不相邻的数字重复（如 2026） | 对四个数字做全部六组两两比较 |
| 找到答案后忘记 `break` | 后续可能继续输出更多满足条件的年份 | 输出第一个符合条件的年份后 `break;` |

## 三、今日复盘

**这道题的通用思路：**

> 从小到大枚举候选值 → 提取信息 → 判断是否符合条件 → 找到第一个即停止。

**需要真正掌握的要点：**

1. `% 10` 提取个位；`/ 10` 去掉个位；多位数也可用 `/ 10^k % 10` 提取对应数位。
2. 检查“四个数两两不同”需要六次独立比较，而不只是比较相邻两位。
3. 从小到大枚举配合 `break`，可以直接保证答案最小。
4. `while (n--)` 用于处理已知组数的多组输入；`n` 每次循环都会递减。
5. 注意输入格式和“是否保证有解”的题目边界，不能脱离题面假设。
