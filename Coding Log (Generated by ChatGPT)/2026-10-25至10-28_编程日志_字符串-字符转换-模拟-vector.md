## 1. 总览：新增知识与典型错误

| 当时的疑问或报错 | 核心原因 | 关键结论 |
|---|---|---|
| `string` 怎样删除最后一个字符？ | 不清楚 `pop_back` / `erase` | 非空时 `s.pop_back()` |
| `scanf` 怎样读 `string`？ | `%s` 需要字符缓冲区，不是 `std::string*` | `cin >> s`；或先读 `char[]` |
| 输入 `原串, 子串1, 子串2` 怎么拆？ | 空格与逗号的分隔规则不同 | `getline(ss, item, ',')` + 适当去空格 |

| 数字 65 怎样变 `'A'`？`"09"` 怎样变 9？ | ASCII 码、数字字符和数值混淆 | `char(65)`；`stoi("09")` |
| 压缩字符串时出现 `"` / `?` | ASCII 换算符号错误、判断 `s[i]` 却输出 `s[i-1]` | 始终以**刚结束的字符组**为准 |

| 程序一直处于输入模式 | 内层 `for` 把 `j++` 误写成 `i++` | 检查初始化、条件、增量对应同一变量 |
| `size of array 's' has non-integral type 'double'` | `1e4` 是浮点字面量 | 用 `10001` 或 `constexpr int` |
| 电灯状态和输出不对 | `rev(i)` 应是 `rev(j)`；`first=false` 放错处 | 区分操作的人和被操作的灯 |
| 回形遍历重复元素 | 中间只剩一行/一列仍继续走其他方向 | 每方向检查边界，或用方向 + `visited` |

## 2. `string` 删除末尾字符与基础操作

### 2.1 最直接：`pop_back()`

```cpp
string s = "hello";
if (!s.empty()) s.pop_back();  // "hell"
```

`pop_back()` 直接删除最后一个字符，通常为 O(1)。**空字符串不能调用**。

### 2.2 `erase()`、`substr()`

```cpp
string s = "abcdef";
s.erase(s.size() - 2);         // "abcd"，从位置 4 删除到末尾

string t = "abcdef";
t = t.substr(0, t.size() - 1); // "abcde"，取得新字符串
```

`erase(pos, len)` 可以删除指定区间：

```cpp
string s = "abcdef";
s.erase(2, 3);  // "abf"，删掉 cde
```

### 2.3 常用速记

```cpp
s.push_back('A');      // 末尾加一个字符
s += 'B';              // 也能追加单个字符
s += "XYZ";           // 追加字符串
s.back();              // 读取最后一个字符（需要非空）
s.pop_back();          // 删除最后一个字符（需要非空）
s.insert(3, "-");     // 下标 3 前插入字符串
s.empty();             // 是否为空
s.size();              // 长度
```

## 3. `scanf`、分隔符与 `stringstream`

### 3.1 `scanf` 为什么不能直接读取 `std::string`？

错误示例：

```cpp
string s;
scanf("%s", &s);    // 错：%s 需要 char*，不是 string*
```

正确方案：

```cpp
string s;
cin >> s;          // 读一个不含空白的单词
```

或使用 C 风格字符数组：

```cpp
char buf[100];
scanf("%99s", buf); // 最多读 99 字符，保留 '\0' 的空间
string s = buf;
```

### 3.2 同一行内用逗号分隔三个字符串

题目里出现过：

```text
abcd123ab888efghij45ef67k1, ab, ef
```

希望得到：

```text
s = abcd123ab888efghij45ef67k1
a = ab
b = ef
```

**方案 A：`scanf` 的扫描集合**

```cpp
char s[1000], a[100], b[100];
scanf(" %999[^,], %99[^,], %99s", s, a, b);
```

`%[^,]` 表示：读到逗号为止（不包括逗号）；`%[^\n]` 表示读到换行为止。**格式中的空格会跳过输入中的空白字符**；扫描集合本身不会自动去掉尾部空格。

**方案 B：`getline()` + `stringstream`（更适合 `std::string`）**

```cpp
#include <iostream>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string line, s, a, b;
    getline(cin, line);             // 一整行
    stringstream ss(line);          // 把这一行当输入流

    getline(ss, s, ',');
    getline(ss >> ws, a, ',');      // 忽略前导空格
    getline(ss >> ws, b);           // 最后一段读到结尾

    cout << s << '\n' << a << '\n' << b << '\n';
}
```

`ws` 是输入流操纵符，跳过前导空白；**不自动删除末尾空格**。如果题目允许字段内部空格或末尾空格，应使用更严谨的 `trim` 逻辑。

### 3.3 `ss >> word` 与 `getline(ss, word, ',')` 的差别

| 写法 | 停止条件 | 适合 |
|---|---|---|
| `cin >> word` | 空格、换行等空白字符 | 键盘/标准输入的单词 |
| `getline(cin, line)` | 换行 | 一整行 |
| `ss >> word` | 空白字符 | 已读到的某一行中的多个单词 |
| `getline(ss, item, ',')` | 逗号 | CSV 风格的简单分隔数据 |

多段逗号分隔：

```cpp
string item;
while (getline(ss >> ws, item, ',')) {
    // 处理 item
}
```

> 这个做法是简单分隔符解析，不是完整 CSV 解析器：不处理引号内部的逗号等复杂规则。

## 4. `find` / `rfind` 与 `string::npos`

### 4.1 单个字符和整个子串都能搜索

```cpp
string s = "abc123abc";

s.find('a');       // 0
s.find("abc");     // 0
s.rfind('a');      // 6
s.rfind("abc");    // 6
s.find('a', 1);    // 从下标 1 开始向右找，结果 6
```

- `find()`：符合条件的**最左边**的匹配起点。
- `rfind()`：符合条件的**最右边**的匹配起点。
- 找不到时返回 `string::npos`。

### 4.2 必须记住的错误：不能写 `find(c) > 0`

```cpp
string s = "PDJWXK";
s.find('P');    // 0：明明找到了
```

如果写 `s.find('P') > 0`，会错过下标为 0 的匹配；而没有找到时返回的 `npos` 又通常会比 0 大，反而可能被判为 `true`。

正确判断：

```cpp
if (s.find('P') != string::npos) {
    // 找到了
}
```

### 4.3 从右边删除最后一次匹配

```cpp
string s = "abc123abc";
size_t pos = s.rfind("abc");
if (pos != string::npos) {
    s.erase(pos, 3);        // "abc123"
}
```

`find` / `rfind` 都**不会修改**原字符串，只返回位置。

## 5. ASCII、`stoi`、数字与字符之间的转换

这几天反复出现的混淆：**整数 9、字符 `'9'`、字符串 `"9"` 是三种不同的数据**。

| 目标 | 写法 | 结果 |
|---|---|---|
| ASCII 数值 65 → 字符 | `char(65)` | `'A'` |
| 字符 `'A'` → ASCII 数值 | `int('A')` | `65` |
| 数字 9 → 字符 | `char('0' + 9)` | `'9'` |
| 字符 `'9'` → 数字 | `'9' - '0'` | `9` |
| 整数 9 → 字符串 | `to_string(9)` | `"9"` |
| 字符 `'A'` → 单字符字符串 | `string(1, 'A')` | `"A"` |
| 数字字符串 `"09"` → 整数 | `stoi("09")` | `9` |

ASCII 数字字符：`'0'`～`'9'` 对应 48～57；大写字母 `'A'` 为 65，小写字母 `'a'` 为 97。

```cpp
string s = "09";
int x = stoi(s);               // 9，不保留前导 0

string result;
result += char(9 + '0');        // result 为 "9"
result += char(65);            // result 为 "9A"
```

**易错区别：**

```cpp
char(9)        // ASCII 码 9：制表符（Tab），不是字符 '9'
char('0' + 9)  // 字符 '9'
to_string(65)  // 字符串 "65"，不是 "A"
```

`stoi()` 对无法解析的内容可能抛出 `invalid_argument`；数值越界可能抛出 `out_of_range`。它也可能只解析字符串开头的有效整数前缀，需要整串合法时应额外检查。

## 6. `<cctype>`、`toupper` / `tolower` 与强制转换

### 6.1 `toupper()`、`tolower()`

```cpp
#include <cctype>

char a = char(toupper('a'));  // 'A'
char b = char(tolower('Z'));  // 'z'
```

`toupper()` / `tolower()` 处理的是**单个字符**，并返回 `int`；它们不会一次处理整个 `string`。

整串统一大小写：

```cpp
string s = "HeLLo";
for (char &c : s) {
    c = char(toupper(static_cast<unsigned char>(c)));
}
// s == "HELLO"
```

对于题目限制的英文 ASCII 字母，直接 `toupper(s[i])` 也可；对于可能包含其他字节的数据，先转 `unsigned char` 更安全。

### 6.2 `char(x)`、`(char)x`、`static_cast<char>(x)`

```cpp
int n = 65;
char a = char(n);
char b = (char)n;
char c = static_cast<char>(n);
// 都得到 'A'
```

- `char(x)`：函数式强制转换。
- `(char)x`：C 风格强制转换。
- `static_cast<char>(x)`：更清晰的 C++ 显式转换方式。

它们**不会自动修复错误的算术表达式**。如果计算得到 ASCII 34，转换后的结果仍然是 `"`。

### 6.3 把下标和字符值分清楚

```cpp
s[i - 1]       // 取前一个字符
s[i] - 1       // 当前字符的 ASCII 数值减 1
```

这两个表达式都能编译，却意义完全不同，是字符串压缩题的关键错误来源。

## 7. 例题「出书最多」：字符频率统计

**题意：** 每本书有书号和大写作者字母串（单本书内作者字母不重复），找出参加编著书籍最多的作者，输出该作者、参与数量、有关书号（按输入顺序）。题目保证最多的作者唯一。

### 7.1 当时的原始错误

**错误 A：内层循环增量写错**

```cpp
for (int i = 0; i < m; i++) {
    for (int j = 0; j < 2; i++) {  // 错：这里应该 j++
        cin >> s[i][j];
    }
}
```

由于 `j` 不增长，`j < 2` 一直为真，`i` 反而不断增加，导致数组越界且程序不断等待输入。

**错误 B：查找作者时使用 `find(author) > 0`**

- 当作者在第 0 位，会错误漏掉该书。
- 当作者不存在，`npos` 又会误被判断为 `> 0`。

**错误 C：漏输出第二行书籍数量**，并且 `max_i` 最好初始化。

### 7.2 更精简的正确模板

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int m;
    cin >> m;
    vector<string> ids(m), authors(m);
    int freq[26] = {0};

    for (int i = 0; i < m; i++) {
        cin >> ids[i] >> authors[i];
        for (char ch : authors[i]) {
            freq[ch - 'A']++;
        }
    }

    int best = 0;
    for (int i = 1; i < 26; i++) {
        if (freq[i] > freq[best]) best = i;
    }

    char author = char('A' + best);
    cout << author << '\n' << freq[best] << '\n';
    for (int i = 0; i < m; i++) {
        if (authors[i].find(author) != string::npos) {
            cout << ids[i] << '\n';
        }
    }
}
```

**高频模式：** `a[ch - 'A']++` 进行字母频率统计，`char('A' + best)` 转回字符；先统计 → 找最大 → 回扫输出。由于每本书作者串无重复，字母出现次数就等于参与编写的书本数。

## 8. 例题「字符串行程长度压缩」：连续分组

**题意：** 将连续且忽略大小写的相同字母压缩成 `(大写字母,次数)`，多组输入读到 EOF；OJ 要求形如 `(A,3)(B,1)`，**组与组之间、逗号后均无空格**。

输入：

```text
aaabbbcccd
aAABBbCCCaaaaa
```

正确输出：

```text
(A,3)(B,3)(C,3)(D,1)
(A,3)(B,4)(C,3)(A,5)
```

### 8.1 第一类错误：大小写 ASCII 换算写反

当时写过类似：

```cpp
char(s[i] - ('A' - 'a'))  // 'A'-'a' 为 -32，反而加了 32
```

小写转大写可用 `char(c - 'a' + 'A')`，但更推荐 `toupper(c)`。

### 8.2 第二类错误：判断下一字符，输出上一组却取错对象

当 `s[i]` 与 `s[i-1]` 不同时，**刚结束的那组属于 `s[i-1]`**。

```text
下标：0 1 2 3
字符：a a a b
           ↑
        i=3 时，结束的是 a 组，而不是 b 组
```

原代码曾用 `s[i] >= 'a'` 判断大小写，实际却转换 `s[i-1]`，于是当 `s[i]='c'`、`s[i-1]='B'` 时，把 `'B'` 减去 32，得到 ASCII 34 的 `"`。

**准则：判断和输出必须围绕同一个组代表字符进行。**

### 8.3 第三类错误：`s[i] - 1` 误写成前一项

OJ 提示：标准输出 `(A,64)`，提交结果却是 64 个 `(A,1)`。

```cpp
// 错误：让当前字符的编码减 1
toupper(s[i] - 1)

// 正确：读下标为 i-1 的字符
toupper(s[i-1])
```

两个 `toupper` 之间始终不相等，`cnt` 便无法累积。

### 8.4 边界：末尾如何输出最后一组？

可以像原思路一样追加哨兵：`s += ' ';`，让最后一组触发“变化”分支。更稳妥的写法是不追加哨兵，直接让 `i` 走到 `s.size()`，并利用短路判断规避非法访问。

### 8.5 可直接复用的正确代码

```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

int main() {
    string s;
    while (cin >> s) {
        int cnt = 1;
        for (int i = 1; i <= (int)s.size(); i++) {
            if (i < (int)s.size() &&
                toupper(s[i]) == toupper(s[i - 1])) {
                cnt++;
            } else {
                cout << '(' << char(toupper(s[i - 1]))
                     << ',' << cnt << ')';
                cnt = 1;
            }
        }
        cout << '\n';
    }
}
```

这里 `i == s.size()` 时，`&&` 左侧为假，因此**不会访问 `s[i]`**；直接进入 `else` 输出最后一组。

### 8.6 迁移到其他题目

这是「连续相同元素分段（Run-Length Encoding）」模板，除了字符串，也能用于数组的连续段计数、连续成绩统计、相邻状态归并等。处理时始终区分**组的代表值**与**当前扫描位置**。

## 9. 二维 `string` 数组排序与关联数据

问题：`string s[1005][2]` 能否按第二列的字典序排序？可以，但**排序时要保持整行数据的对应关系**。

原始形式：

```cpp
string s[3][2] = {
    {"233", "PDJWXK"},
    {"307", "F"},
    {"410", "GPKCV"}
};
```

### 9.1 普通二维数组：手动交换两列

```cpp
for (int i = 0; i < 3; i++) {
    for (int j = i + 1; j < 3; j++) {
        if (s[i][1] > s[j][1]) {
            swap(s[i][0], s[j][0]);
            swap(s[i][1], s[j][1]);
        }
    }
}
```

C 风格二维数组的整行类型是原生数组，不能直接像单个 `string` 那样赋值和交换，因此不宜直接 `sort(s, s + n)`；如果只是**某一行内部**排序，可 `sort(s[0], s[0] + 2)`。

### 9.2 更方便：把一整行作为一个对象

```cpp
#include <algorithm>
#include <vector>
#include <utility>

vector<pair<string, string>> books = {
    {"233", "PDJWXK"}, {"307", "F"}, {"410", "GPKCV"}
};

sort(books.begin(), books.end(),
     [](const pair<string,string>& a, const pair<string,string>& b) {
         return a.second < b.second;
     });
```

当信息属于同一个对象（书号与作者），使用 `pair` 或 `struct` 会更安全。

**注意：**「出书最多」原题要求书号按输入顺序输出，所以那题实际上**不需要排序**。

## 10. 编译错误：`1e4` 不能直接作为普通数组长度

原代码：

```cpp
string eml, s[1e4+1][3];
```

编译报错：

```text
[Error] size of array 's' has non-integral type 'double'
```

原因是 `1e4` 在 C++ 中是 `double` 类型的浮点字面量（值虽然是 10000），`1e4+1` 仍是浮点类型。普通数组维度要求整数常量表达式。

```cpp
string s[10001][3];            // 正确
constexpr int MAXN = 10001;
string t[MAXN][3];             // 正确
```

如果行数 `n` 是运行时才知道：

```cpp
vector<vector<string>> a(n, vector<string>(3));
```

> 局部定义很多 `string` 对象可能占用较多栈内存；若 OJ 栈空间紧张，优先考虑动态容器或根据题意减少存储。

## 11. 例题「开关电灯」：状态翻转与倍数

**题意：** 共有 1～N 号灯。第一个人全关；从第 2 人起，第 `i` 个人反转所有编号为 `i` 倍数的灯。输出最后亮着的灯。

### 11.1 原代码的两个关键错误

```cpp
for (int i = 2; i <= N; i++) {
    for (int j = 1; j <= N; j++) {
        if (j % i == 0) rev(i);  // 错，应是 rev(j)
    }
}
```

`i` 是**操作的人**，`j` 是**被操作的灯**。满足倍数条件时应该反转 `j`，不是反转 `i`。

另一个错误：`first = false` 放在 `if (a[i])` 外面，会在没输出灯号时就认为已输出，导致行首空格。

### 11.2 正确且简洁的模拟

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    int a[1001] = {0};           // 全关

    for (int i = 2; i <= N; i++) {
        for (int j = i; j <= N; j += i) {
            a[j] = 1 - a[j];     // 翻转 0 <-> 1
        }
    }

    bool first = true;
    for (int i = 1; i <= N; i++) {
        if (a[i]) {
            if (!first) cout << ' ';
            cout << i;
            first = false;       // 必须在真正输出后更新
        }
    }
}
```

输入 `8` 时输出：`2 3 5 6 7 8`。

### 11.3 更深一层的数学结论

第 `x` 盏灯的操作人数 = `x` 的**正因数个数减去 1**（第 1 个人只关灯，不计反转）。一个数因数个数为奇数，当且仅当它是**完全平方数**。因此：

- 完全平方数编号的灯，反转偶数次，最终熄灭；
- 非完全平方数编号的灯，反转奇数次，最终亮着。

所以还有更简单的数学解法：枚举 `1..N`，输出所有**非完全平方数**。但如果题目目的是训练模拟，前面的做法更贴近题意。

## 12. 二维 `vector`、定长 `array` 与 `pair`

### 12.1 `vector<vector<int>>`：动态二维矩阵

```cpp
#include <vector>
vector<vector<int>> a(3, vector<int>(4, 0)); // 3 行 4 列，全 0

a[1][2] = 10;
a.push_back({1, 2, 3});   // 添加一行
a[0].push_back(99);     // 第 0 行添加一个元素
```

- `a.size()`：行数；`a[i].size()`：第 `i` 行的元素个数。
- 可以不规则：每行长度不必相同。
- 访问 `a[i][j]` 时必须保证对应行、列存在。

它与此前数位和分组题的 `vector<int> group[37]` 很相似：

```cpp
vector<vector<int>> group(37);
group[3].push_back(12);
group[3].push_back(21);
```

### 12.2 `vector` 可以放“普通数组”吗？

`vector<int[3]>` 不是适合的标准容器元素用法；固定长度的多个整数建议使用 `std::array`：

```cpp
#include <array>
#include <vector>
vector<array<int, 3>> v;
v.push_back({1, 2, 3});
v.push_back({4, 5, 6});
cout << v[0][1];                // 2
```

如果已经有原生数组：

```cpp
int raw[3] = {1, 2, 3};
vector<int> v(raw, raw + 3);    // 复制元素到 vector
```

长度不固定时，使用 `vector<vector<int>>`。

### 12.3 专门存储二维坐标：`pair<int,int>`

```cpp
#include <utility>
#include <vector>
using namespace std;

pair<int,int> p = {3, 5};
cout << p.first << ' ' << p.second; // 3 5

vector<pair<int,int>> points;
points.push_back({1, 2});
points.push_back({3, 4});
```

`pair` 默认比较时先看 `.first`，若相同再比较 `.second`。若坐标还需要额外属性、距离或几何方法，也可以定义：

```cpp
struct Point { int x, y; };
```

C++17 还可以使用 `auto [x, y] = p;`。

## 13. 例题「二维数组回形遍历」：边界法与方向法

**题意：** 从 `a[0][0]` 出发，按右 → 下 → 左 → 上不断绕圈，由外向内遍历整个矩阵，每个元素只输出一次。

例如：

```text
1  2  3  4
12 13 14 5
11 16 15 6
10 9  8  7
```

输出顺序是 `1,2,...,16`（每个数字一行）。

### 13.1 原程序的问题

原思路用 `vector<pair<int,int>> index` 保存坐标，并不断调整 `r、c、r1、c1`。主要问题：

- 只在外层 `while (index.size() < n)` 检查是否完成；
- 走完最后一行或最后一列时，**同一轮中仍执行后续方向**，重复访问元素；
- 原本表示总行数/总列数的 `r、c` 又被用于表示缩小后的边界，含义容易混乱。

特别要测试：`1×4`、`4×1`、`3×3`、`4×4`、`3×4`。

### 13.2 方法 A：四个边界（不需要 visited）

```cpp
int top = 0, bottom = r - 1;
int left = 0, right = c - 1;

while (top <= bottom && left <= right) {
    for (int j = left; j <= right; j++) cout << a[top][j] << '\n';
    top++;

    for (int i = top; i <= bottom; i++) cout << a[i][right] << '\n';
    right--;

    if (top <= bottom) {
        for (int j = right; j >= left; j--) cout << a[bottom][j] << '\n';
        bottom--;
    }

    if (left <= right) {
        for (int i = bottom; i >= top; i--) cout << a[i][left] << '\n';
        left++;
    }
}
```

一句话理解：**每走完一个方向，把尚未访问的矩形区域缩小一圈。**

### 13.3 方法 B：方向数组 + `visited`（更通用）

顺时针四方向：

| 方向编号 `d` | 方向 | 行变化 `dx[d]` | 列变化 `dy[d]` |
|---|---|---:|---:|
| 0 | 右 | 0 | 1 |
| 1 | 下 | 1 | 0 |
| 2 | 左 | 0 | -1 |
| 3 | 上 | -1 | 0 |

```cpp
int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};
```

`x,y` 表示**当前行列**，`d` 表示方向编号；下一步：

```cpp
int nx = x + dx[d];
int ny = y + dy[d];
```

如果下一步**越界或访问过**，就转弯：

```cpp
d = (d + 1) % 4; // 右 -> 下 -> 左 -> 上 -> 右
```

完整独立模板：

```cpp
#include <iostream>
using namespace std;

int a[101][101];
bool vis[101][101] = {false};

int main() {
    int r, c;
    cin >> r >> c;
    for (int i = 0; i < r; i++)
        for (int j = 0; j < c; j++)
            cin >> a[i][j];

    int dx[4] = {0, 1, 0, -1};
    int dy[4] = {1, 0, -1, 0};
    int x = 0, y = 0, d = 0;

    for (int step = 0; step < r * c; step++) {
        cout << a[x][y] << '\n';
        vis[x][y] = true;

        // 最后一个元素无需再移动
        if (step == r * c - 1) break;

        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || nx >= r || ny < 0 || ny >= c || vis[nx][ny]) {
            d = (d + 1) % 4;
            nx = x + dx[d];
            ny = y + dy[d];
        }
        x = nx;
        y = ny;
    }
}
```

**时间复杂度：** O(r×c)。边界法辅助空间 O(1)；方向法额外 `visited` 空间 O(r×c)。方向数组 + 转向的思路以后还能用于迷宫、机器人模拟、二维网格搜索。

### 13.4 为什么 `d=(d+1)%4` 是循环访问？

编号只有 0,1,2,3，增量后取模自然实现 `0→1→2→3→0`。这是之前学的**循环下标**技巧在二维方向上的应用。

## 14. 例题「478-3279」：字符映射与格式化

**题意：** 把便于记忆的七位电话号码转换成 `xxx-xxxx`。数字保留，字母按电话键盘映射（题目中 `Q`、`Z` 不映射），原有连字符忽略。

映射表：

| 字母 | 数字 |
|---|---|
| ABC | 2 |
| DEF | 3 |
| GHI | 4 |
| JKL | 5 |
| MNO | 6 |
| PRS | 7 |
| TUV | 8 |
| WXY | 9 |

### 14.1 先映射，后格式化

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    string groups[8] = {
        "ABC", "DEF", "GHI", "JKL", "MNO", "PRS", "TUV", "WXY"
    };

    for (int t = 0; t < n; t++) {
        string s, ans;
        cin >> s;

        for (char c : s) {
            if (c >= '0' && c <= '9') {
                ans += c;
            } else if (c >= 'A' && c <= 'Z') {
                for (int j = 0; j < 8; j++) {
                    if (groups[j].find(c) != string::npos) {
                        ans += char('2' + j);
                        break;
                    }
                }
            }
            // '-' 没命中任何分支，自动忽略
        }

        ans.insert(3, "-");
        cout << ans << '\n';
    }
}
```

输入 `ITS-EASY` → 先得到 `4873279` → 输出 `487-3279`。输入 `3-10-10-10` → `310-1010`。

### 14.2 为什么 `'-'` 会被跳过？

`for(char c:s)` 每轮取一个字符。由于 `'-'` 既不是数字、也不是大写字母，不会执行任何追加操作，下一轮直接处理下一个字符。

还可以显式表达：

```cpp
for (char c : s) {
    if (c == '-') continue;
    // 处理其他字符
}
```

不要写 `break`，否则读到第一个 `-` 就会终止整个循环。

### 14.3 `insert()` 的好处

```cpp
ans.insert(3, "-");
```

已生成的七位数字中，下标为 3 的位置正好是第四个字符之前。**分两步做「数据规范化」与「格式化」，比边转换边计算连字符位置更不容易错。**

## 15. 范围 `for`、`continue` 与 `break`

### 15.1 `for (char c : s)` 是什么？

C++11 的**范围 `for` 循环**：按顺序依次取得字符串中的每个字符。

```cpp
string s = "ABC";
for (char c : s) cout << c << '\n';
```

等价于逐个读取 `s[i]`，但不需要维护下标。

区别：

```cpp
for (char c : s)  c = 'X';   // c 是副本，不修改 s
for (char &c : s) c = 'X';   // c 是引用，修改 s 本体
```

范围 `for` 不只用于字符串，也能处理：

```cpp
for (int x : nums) { /* vector<int> */ }
for (auto p : points) { /* vector<pair<int,int>> */ }
```

### 15.2 `continue` 与 `break`

```cpp
for (char c : s) {
    if (c == '-') continue; // 只跳过这轮，继续下一个字符
    cout << c;
}
```

```cpp
for (char c : s) {
    if (c == '-') break;    // 终止整个当前层循环
    cout << c;
}
```

| 语句 | 语义 |
|---|---|
| `continue` | 跳过本轮剩余语句，进入下一轮 |
| `break` | 退出最近一层循环（或 switch） |

## 16. 错误速查表与复习清单

### 16.1 高频错误速查

| 错误写法 | 正确写法 / 判断 |
|---|---|
| `scanf("%s", &s)`，其中 `s` 是 `std::string` | `cin >> s`，或 `char buf[]` + `scanf` |
| `s.find(c) > 0` | `s.find(c) != string::npos` |
| `char(9)` 想得到字符 `'9'` | `char('0'+9)` |
| `to_string(65)` 想得到字符 `A` | `char(65)` 或 `string(1,char(65))` |
| `toupper(s[i] - 1)` 想访问前一位 | `toupper(s[i-1])` |
| 判断 `s[i]` 却要输出刚结束的组 | 应以 `s[i-1]` 为组代表 |
| `i <= s.size()` 且直接访问 `s[i]` | 先判断 `i < s.size()`；或使用哨兵 |
| `for (int j=0; j<2; i++)` | `j++` |
| `int a[1e4+1]` | `int a[10001]` / `constexpr int` |
| `if (j % i == 0) rev(i)` | `rev(j)` |
| `first=false` 放在输出条件外 | 真正输出一个元素后才更新 |
| 回形遍历只在外圈开始判断结束 | 每段后判断边界，或使用 `visited` |
| 在电话号码中遇 `-` 就 `break` | `continue` 或无需任何操作 |
| `s.pop_back()` 没检查空串 | `if (!s.empty()) s.pop_back()` |

int cnt[26] = {0};

**四方向：**
