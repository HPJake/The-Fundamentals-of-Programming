## 二、DFS、回溯与递归

### 1. 1139「棋盘问题」：从八皇后迁移到带障碍的选位搜索

**我的提问**：看到新的棋盘放置题，应当用什么思路？

**题意**：给定一个 `n × n` 棋盘，只有 `#` 位置可放棋子，放恰好 `k` 个；两棋子不能同一行或同一列。可能有多组数据，以 `-1 -1` 结束。

**回答与收获**：使用 **DFS + 回溯**。按行搜索，每行有两类选择：

- **跳过这一行**：`dfs(row + 1, placed)`；
- **在这一行选一列**：要求 `board[row][col] == '#'` 且 `usedCol[col] == false`，选后递归 `dfs(row + 1, placed + 1)`，返回后将 `usedCol[col]` 复原为 `false`。

因为一层递归只管一行，所以不必另开 `usedRow`；本题不限制斜线，因此也不用八皇后的 `diag1 / diag2`。

```cpp
void dfs(int row, int placed) {
    if (placed == k) { // 找到一种完整方案
        ans++;
        return;
    }
    if (row == n) return; // 行用完但棋子没放够

    dfs(row + 1, placed); // 本行不放

    for (int col = 0; col < n; col++) {
        if (board[row][col] != '#' || usedCol[col]) continue;
        usedCol[col] = true;
        dfs(row + 1, placed + 1);
        usedCol[col] = false; // 恢复本层修改
    }
}
```

**后续讨论：多组输入需要 `memset` 吗？**

- 正确回溯后，`usedCol` 会恢复到 DFS 进入前的状态；若初始全为 `false`，每轮搜索结束也全为 `false`，理论上不必每组都 `memset`。
- 但每组的答案计数器 `ans` 必须设回 `0`；它是累加结果，不是应回溯的临时状态。
- 每组棋盘需要重新读入；显式清空 `usedCol` 也可以作为保险。

**原理总结**：*谁修改共享搜索状态，谁负责恢复；全局答案计数不应回退。*

### 2.「集合里的乘法」：选或不选型 DFS 的实际代码错误

**我的原代码关键行（有错误）**：

```cpp
dfs(id + 1, product *= s[id]); // 选
 dfs(id + 1, product);          // 不选
```

**错误原因**：`*=` 是复合赋值，会直接修改当前层的 `product`。第一个分支返回后，第二个分支看到的已经不是原乘积。这里不属于函数传值自动恢复的问题，而是**先改了调用者自己的变量**。

**正确写法**：

```cpp
dfs(id + 1, product * s[id]); // 选：只计算新值，不修改本层
 dfs(id + 1, product);         // 不选：沿用原值
```

题目还要求选出**非空子集**，所以必须防止所有元素都不选时把空集的乘积 `1` 当作合法答案。可加参数 `bool chosen`：

```cpp
void dfs(int id, long long product, bool chosen) {
    if (id == n) {
        if (chosen && product == t) ans = true;
        return;
    }
    if (ans) return;
    dfs(id + 1, product * s[id], true);
    dfs(id + 1, product, chosen);
}
// dfs(0, 1, false);
```

`long long` 能降低溢出风险，但仍有数值范围限制；若元素很大还需额外防护。

**本题与之前「最佳凑单」对应**：加法用初始值 `0`（`sum + a[i]`），乘法用初始值 `1`（`product * a[i]`）。

### 3.「猴子爬山」：递归可以不显式回溯

**题意**：猴子要爬 `m ≤ 40` 级，每次跳 `1、3、5` 级；顺序不同算不同跳法。样例 `m=6` 答案为 `8`。

**DFS 写法**：

```cpp
void dfs(int step) {
    if (step == m) { ans++; return; }
    if (step > m) return;
    dfs(step + 1);
    dfs(step + 3);
    dfs(step + 5);
}
```

**为什么不用撤销？** `step` 按值传递，调用 `dfs(step + 1)` 不会改变当前层的 `step`。只要没有修改共享数组，就无需 `pop_back()` / 恢复标记。

**更优方案**：令 `f(x)` 为还剩 `x` 级的跳法数：

\[
f(x)=f(x-1)+f(x-3)+f(x-5),\quad f(0)=1,\quad f(x<0)=0.
\]

直接 DFS 会反复计算相同状态，利用记忆化搜索或 DP 可以优化。

### 4.「装载问题」：只搜索第一艘船，并保存最优方案

**我的提问**：怎么判断是否能装载成功？为什么数组原来开 `100`？之后提交了自己的 DFS 代码，又问如何换成 `vector`、`resize(n,0)` 的 `0` 是什么。

**题意**：把每个集装箱完整分配到两艘船，载重上限分别是 `c1` 和 `c2`；希望第一艘船尽量满，且能输出两艘船各装哪些物品。

设 `total = sum(w[i])`，DFS 求出第一艘船在 `sum <= c1` 下能达到的最大装载重量 `best`。第二艘船装下全部剩余集装箱当且仅当：

\[
\boxed{total-best\le c_2}
\]

这一判断成立的原因是：第一艘船装得越多，第二艘船需要承担的重量就越少；`best` 已经保证 `<= c1`。

**不能只看 `total <= c1+c2`**：例如两船容量均为 5，箱子重 `4、4、2`，总重虽然恰好是 10，但无法无拆分地分配成两组各不超过 5。

#### 我的代码真实错误：保存最优方案的缩进 / 作用域

原代码：

```cpp
if (id == n) {
    if (best < sum) best = sum;
    for (int i = 0; i < n; i++) {
        bestChosen[i] = chosen[i]; // 错！每个合法叶子都会覆盖
    }
    return;
}
```

问题：`best` 只有更优时才更新，而 `bestChosen` **每次**都覆盖；DFS 最后可能走到空方案，导致记录的最优重量与方案不对应。

修正：

```cpp
if (id == n) {
    if (sum > best) {
        best = sum;
        bestChosen = chosen; // 同时保存与 best 配套的方案
    }
    return;
}
```

**正确的 DFS 主体（使用 vector）**：

```cpp
vector<int> w, chosen, bestChosen;
int n, c1, c2, best = 0;

void dfs(int id, int sum) {
    if (sum > c1) return;
    if (id == n) {
        if (sum > best) {
            best = sum;
            bestChosen = chosen;
        }
        return;
    }

    chosen[id] = 1;              // 放到第一艘船
    dfs(id + 1, sum + w[id]);
    chosen[id] = 0;              // 回溯，恢复当前标记
    dfs(id + 1, sum);            // 剩下的交给第二艘船
}
```

`chosen` 是**临时状态**，需要回溯；`bestChosen` 是**答案快照**，不能跟着回溯清空。

**为什么原来开 `w[100]`？** `100` 只是演示代码里的任意预留大小，不是已证实的题目约束。若 `n>100` 就可能越界；更规范地按输入动态分配：

```cpp
cin >> n;
w.resize(n);
chosen.resize(n, 0);
bestChosen.resize(n, 0);
```

**`resize(n, 0)` 里的 0** 是“新增元素的初始值”。`resize` 只改变数量，并给新增元素设置值，**不会把已有元素全部改成 0**；需要清空现有值时用 `fill(v.begin(), v.end(), 0)`。与 `reserve(n)` 不同，后者只预留容量，不增加可下标访问的元素。

**`bestChosen = chosen`** 对 `vector<int>` 是整份内容复制，之后修改 `chosen` 不影响 `bestChosen`。

### 5.「五子棋判输赢」：落子模拟 + 四方向检查

**我的提问**：给定双方落子顺序，如何判定最早获胜的一步？随后要求完整代码。

答案：不需要 DFS。按输入顺序落子，每次只检查**新落下的棋子**是否连成 5 颗，因为胜利如果刚刚出现，一定包含这颗新棋。

四条直线方向：

```cpp
int dx[4] = {1, 0, 1, 1};
int dy[4] = {0, 1, 1, -1};
```

每个方向都要正反两侧检查，计数初始 `cnt=1`（包含新落子），`cnt>=5` 就获胜。

```cpp
int nx = x + sign * step * dx[d];
int ny = y + sign * step * dy[d];
// 如果棋盘以 [行][列] 存储，访问的是 board[ny][nx]
```

注意坐标：输入 `(x,y)` 是横纵坐标，二维数组常按 `board[y][x]` 存；黑棋先手，第 `i` 次（从 0 开始）为 `player=i%2`，输出步数 `i+1`。样例结果 `9 0`。

### 6. `map` 如何输出

**我的提问**：`map` 如何打印？

最推荐：

```cpp
for (const auto& p : mp) {
    cout << p.first << ' ' << p.second << '\n';
}
```

- `.first` 是键、`.second` 是值；普通 `map` 按**键从小到大**遍历。
- 也能用迭代器 `it->first`、`it->second`。
- `mp[i]` 是找**键为 i** 的元素，不是“第 i 个元素”；不存在时可能插入新项。
- `for (auto [key, value] : mp)` 是 C++17 的结构化绑定写法。

### 7.「W 的密码」：分组循环移位与位置映射

**我的提问**：请先给完整程序，作业后复盘。

字符被分成三组：`a~i`、`j~r`、`s~z` 加下划线。每组字符仅在该组原先占据的字符串位置之间移动；**解密是右移** `k1/k2/k3` 位。不能简单地对整个字符串右移或对字母编码加数字。

```cpp
vector<int> pos[3]; // 各组在原字符串里的下标
// 将每个字符的位置 i 加入对应的 pos[g]

string ans = s;
for (int g = 0; g < 3; g++) {
    int len = (int)pos[g].size();
    if (len == 0) continue; // 防止 % 0
    int shift = k[g] % len;
    for (int j = 0; j < len; j++) {
        int oldPos = pos[g][j];
        int newPos = pos[g][(j + shift) % len];
        ans[newPos] = s[oldPos];
    }
}
```

重点：`% len` 实现循环位置，必须处理 `len==0`。输入多组数据，遇到 `0 0 0` 停止。

### 8.「变幻的矩阵」：直接检查坐标映射

**我的提问**：先给代码，之后复盘。

对原矩阵 `a` 与目标矩阵 `b`，0 下标时的四种关系：

| 规则 | 检查条件 |
| --- | --- |
| 顺时针 90° | `b[i][j] == a[n - 1 - j][i]` |
| 逆时针 90° | `b[i][j] == a[j][n - 1 - i]` |
| 旋转 180° / 中心对称 | `b[i][j] == a[n - 1 - i][n - 1 - j]` |
| 不变 | `b[i][j] == a[i][j]` |

检查完按 `1、2、3、4` 优先顺序输出第一个匹配项，都不匹配输出 `5`。样例为 `3`。

### 9.「发水果」：逆时针螺旋遍历与方向数组

**我的提问**：这是不是模拟？希望引导写代码。之后进一步问：顺时针能否调整方向数组顺序？`i=(i+1)%k` 是否可以循环遍历？

**逆时针从左上角出发**，先下→右→上→左：

```cpp
// x 表示行，y 表示列
int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};
int dir = 0;
```

每次输出并标记当前位置；若下个位置越界或已经 `visited`，就转弯并重算坐标：

```cpp
int nx = x + dx[dir];
int ny = y + dy[dir];
if (nx < 0 || nx >= n || ny < 0 || ny >= m || visited[nx][ny]) {
    dir = (dir + 1) % 4;
    nx = x + dx[dir];
    ny = y + dy[dir];
}
```

必须先判断下标边界，再访问 `visited[nx][ny]`。总共输出 `n*m` 个数，最后一个输出后不必再移动。

**改成顺时针**：右→下→左→上，只改方向数组即可：

```cpp
int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};
```

转弯仍用 `dir = (dir + 1) % 4`。

**取模循环的规律**：

```cpp
i = (i + 1) % k; // 在 0,1,...,k-1 之间循环
```

它只是计算下一个下标，**不会让循环自动执行 k 次**。且 `k` 必须大于 0；想走 `s` 步可写 `(i+s)%k`（这里假定非负移动）。

### 10.「最小外包矩形」：map 分组 + 最小最大值

**我的提问**：如何求多个几何对象的外包矩形？

对同 ID 的点维护 `minX,minY,maxX,maxY`：

```cpp
struct Rect { int minX, minY, maxX, maxY; };
map<int, Rect> mp;

if (mp.find(id) == mp.end()) {
    mp[id] = {x, y, x, y}; // 首次出现，按当前点初始化
} else {
    mp[id].minX = min(mp[id].minX, x);
    mp[id].minY = min(mp[id].minY, y);
    mp[id].maxX = max(mp[id].maxX, x);
    mp[id].maxY = max(mp[id].maxY, y);
}
```

**易错点**：不能在尚未初始化该 ID 时就默认认为 `minX/minY` 为真实最小值，因为 `mp[id]` 会创建默认值（整数成员可能为 0）；如果所有坐标为正，错误地把 0 当最小值。`map` 已经按 ID 升序，不需要额外排序。

### 11.「魔王军队」：最少观察之石（待复盘）

**我的提问**：先完成作业，请给完整代码，并标记以后重点讨论。

士兵在数轴上，观察之石必须放在士兵处，覆盖左右距离各 `R`，目标是最少颗数覆盖全部人。

贪心步骤（排序后从左往右）：

1. 找最左未覆盖士兵 `left=a[i]`。
2. 在能覆盖他的士兵位置中，选**最靠右**的位置放石头。
3. 跳过这个石头能覆盖的所有后续士兵。

```cpp
sort(a.begin(), a.end());
int i = 0, ans = 0;
while (i < n) {
    int left = a[i];
    while (i < n && a[i] <= left + R) i++;
    int stone = a[i - 1];
    while (i < n && a[i] <= stone + R) i++;
    ans++;
}
```

第一个 `while` 是**选最合适的放石位置**；第二个 `while` 是**跳过该石头覆盖的士兵**。输入以 `-1 -1` 结束。待复盘重点是交换论证与双 `while`。

### 13.「佩奇的勇气机」：倒推比正向搜索更简单

**题意**：初始 0，按钮 N 为 `2*x+1`、G 为 `2*x+2`，求把 0 变成目标 `n` 的操作序列。

最后一步可以由目标奇偶性唯一决定：

- 奇数：最后一定是 N，前一个值 `(n-1)/2`；
- 偶数：最后一定是 G，前一个值 `(n-2)/2`。

```cpp
string ans;
while (n > 0) {
    if (n % 2) { ans += 'N'; n = (n - 1) / 2; }
    else       { ans += 'G'; n = (n - 2) / 2; }
}
reverse(ans.begin(), ans.end());
```

注意记录顺序是从最后一步往前，所以最后反转；例如 `20 → "NGNG"`。算法复杂度 `O(log n)`。

### 14.「相关月」：算日期差并对 7 取模

**题意**：同一年中，两个月的 1 日是否恰逢相同星期？

只需判断两个日期从 1 月 1 日开始的天数偏移差是否被 7 整除，**不需要求出具体星期几**。

```cpp
bool isLeap(int y) {
    return y % 400 == 0 || (y % 4 == 0 && y % 100 != 0);
}
int days[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
if (isLeap(year)) days[2] = 29;
int first[13] = {};
for (int m = 2; m <= 12; m++) first[m] = first[m-1] + days[m-1];
// (first[m1] - first[m2]) % 7 == 0 => YES
```

例如平年 2 月到 3 月差 28 天，相关；闰年差 29 天，不相关。

### 15.「传球游戏」：GCD 与模循环（待复盘）

**题意**：`N` 个人围一圈，按固定间隔 `K` 传球，要求第一个人再次持球前所有人都持过球，求最大 `K<=N/2`。

所经过的不同位置数为：

\[
\frac{N}{\gcd(N,K)}.
\]

因此条件是 `gcd(N,K)==1`。从 `N/2` 向下枚举第一个互质的 `K` 即为最大值。示例 `N=9 → K=4`。

```cpp
int gcd(int a, int b) {
    while (b) { int r = a % b; a = b; b = r; }
    return a;
}
```

`std::gcd` 位于 `<numeric>` 且需 C++17；旧平台可用欧几里得算法。

### 17.「田忌赛马」：贪心排序 + 两端指针（待复盘）

**我的提问**：作业优先，先给完整实现。处理多组数据直到 `n==0`。

双方马速均从小到大排序：`tl,tr` 指田忌最慢/最快，`ql,qr` 指齐王最慢/最快。

1. 田忌最快马赢齐王最快马：最快对最快，`+200`。
2. 否则田忌最慢马赢齐王最慢马：最慢对最慢，`+200`。
3. 否则牺牲田忌最慢马对齐王最快马：输则 `-200`，平则 `0`。

```cpp
while (tl <= tr) {
    if (tian[tr] > qi[qr]) { ans += 200; tr--; qr--; }
    else if (tian[tl] > qi[ql]) { ans += 200; tl++; ql++; }
    else {
        if (tian[tl] < qi[qr]) ans -= 200;
        tl++; qr--;
    }
}
```

待复盘重点：第三种情况为什么必须让田忌最慢的马去消耗齐王最快的马，以及怎样用交换论证证明正确。

## 五、动态规划与二进制枚举

### 18.「盗宝」：分组背包 DP（待复盘）

**题意**：每个宝物有重量、价值、洞穴 ID，海盗载重上限为 `m`；**每个洞穴最多拿一件**，求最大总价值。

按洞穴分组，并使用一组旧状态 `dp` 与更新状态 `next`：

```cpp
map<int, vector<pair<int,int>>> caves; // id -> (重量,价值)
vector<int> dp(m + 1, 0);

for (const auto& cave : caves) {
    vector<int> next = dp; // 可以在本洞穴什么都不拿
    for (const auto& item : cave.second) {
        int w = item.first, v = item.second;
        for (int cap = w; cap <= m; cap++) {
            next[cap] = max(next[cap], dp[cap-w] + v);
        }
    }
    dp = next;
}
```

**为什么不能从 `next[cap-w]` 转移？** 那样本组刚拿了一件物品后，可能在同一组又拿第二件，违反“一个洞只进一次”的限制。必须统一从**上一组**的 `dp` 转移。

样例 `m=30`、洞 1 有重 15 价值 8 与重 10 价值 5、洞 2 有重 48 价值 400，答案为 `8`。

### 19.「画家问题」：首行枚举 + 逐行递推 + 真实判题排错（待复盘）

**我的提问**：先给完整代码；随后在线判题报告：

```text
ExitError: exit with exitCode=6 (first diff error in case 0).
Different at line 2.
Std: '28'
Out: '12'
Input:
2
4

yyyy
yyyy
6

```

**题意**：棋盘白 `w`、黄 `y`，求最少涂多少次使全部变黄，无解输出 `inf`。`n<=15`，直接枚举整个棋盘有 `2^(n*n)` 种方案，太大。

**高效算法**：只枚举第一行的 `2^n` 个涂色方案，用第一行和上一行的操作推导下一行，再检查最后一行，取最少涂色次数。复杂度 `O(2^n * n^2)`。

第一行位运算：

```cpp
for (int mask = 0; mask < (1 << n); mask++) {
    // 第 j 列是否涂： (mask >> j) & 1
}
```

**真实错误归属：此前助手的代码漏算了“涂当前格子自身会影响其颜色”这一项**。原实现只计算上、左、右（以及通过下一行反推的下），使 6×6 全白得出 `12`。根据判题标准输出和测试验证，正确模型应是涂一个位置会翻转**当前砖及上下左右**。原题截屏的文字对自身影响描述不够明确，实际应以判题可验证的规则为准。

修复位置一（推算下一行时）：

```cpp
int color = board[i][j]; // w = 1, y = 0
if (i > 0) color ^= paint[i - 1][j];
if (j > 0) color ^= paint[i][j - 1];
if (j + 1 < n) color ^= paint[i][j + 1];
color ^= paint[i][j]; // ★ 之前漏掉：当前位置自身的涂色影响
paint[i + 1][j] = color;
```

修复位置二（检查最后一行时）：

```cpp
int color = board[n - 1][j];
if (n > 1) color ^= paint[n - 2][j];
if (j > 0) color ^= paint[n - 1][j - 1];
if (j + 1 < n) color ^= paint[n - 1][j + 1];
color ^= paint[n - 1][j]; // ★ 同样补上自身影响
if (color != 0) return INT_MAX;
```

**核对结果**（用相同首行枚举算法独立计算）：

| 输入棋盘 | 漏掉自身影响 | 补上自身影响 |
| --- | ---: | ---: |
| 5×5 全白 | `inf` | `15` |
| 6×6 全白 | `12` | **`28`** |

**今日教训**：模拟题的公式必须先完全落实题目中的影响范围。遇到 Wrong Answer，不能只检查枚举和边界，也要重新核对**操作本身改变哪些位置**；标准答案有时可以帮助定位理解中的遗漏。

## 六、今日调试错误与防错清单

| 题目 | 错误主体 | 错误写法 / 现象 | 原因 | 正确处理 |
| --- | --- | --- | --- | --- |
| 集合里的乘法 | 我的代码 | `product *= s[id]` 作为递归实参 | 修改本层 `product`，污染“不选”分支 | `product * s[id]`，另用 `chosen` 排除空集 |
| 装载问题 | 我的代码 | `bestChosen` 每个叶子都复制 | 最优重量和方案可能不一致 | 只在 `sum > best` 内同时更新 `best`、`bestChosen` |
| 装载问题 | 代码设计隐患 | 固定 `w[100]` | `100` 非题目确认上限，n 过大可能越界 | 用 `vector` 按 n 分配 |
| 画家问题 | 此前助手代码 | 6×6 全白 `Out=12`，标准 `28` | 颜色计算漏掉当前格子自身的影响 | 两处都加 `color ^= paint[i][j]`（最后一行用对应下标） |

**防错口诀：**

- **递归传值**：`sum + w[id]` 与 `sum += w[id]` 不一样；`product * s[id]` 与 `product *= s[id]` 不一样。
- **共享标记**：放置 → 递归 → 撤销；更新最优解时保存状态快照。
- **结果计数**：找到一个解 `ans++`，不要回溯 `ans--`。
- **`vector` 长度**：空 `vector` 不能直接写 `v[0]`；先 `resize(n)` 或使用 `push_back()`。
- **循环移动**：`(i+1)%k` 只更新下标；确认 `k>0`。
- **边界访问**：先判断越界，再读取 `board[x][y]` 或 `visited[x][y]`。
- **判题格式**：严格区分 `NO/YES`、`inf`、空格、首行输出、结束标记。
