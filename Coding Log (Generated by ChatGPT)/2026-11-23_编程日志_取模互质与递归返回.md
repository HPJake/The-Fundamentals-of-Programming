## 2. 「传球游戏」：从模拟到互质判定

### 2.1 问题模型

- $N$ 个人围成一圈，编号 $0,1,\ldots,N-1$。
- 从编号 `0` 的人开始；每次顺时针前进 $K$ 个位置传球。
- 要求球**第一次回到起点之前**，每个人都至少接到过一次球。
- 在 $1\le K\le \lfloor N/2\rfloor$ 中找出**最大合法的 $K$**。

设 $x_t$ 表示传球 $t$ 次后的位置：

$$
\boxed{x_0=0,\qquad x_{t+1}=(x_t+K)\bmod N}
$$

于是：

$$
\boxed{x_t=(tK)\bmod N}
$$

### 2.2 两个直观例子

当 $N=8,\ K=2$：

$$
0\to2\to4\to6\to0
$$

只有 4 个不同的人接到球，奇数编号的人始终接不到。

当 $N=8,\ K=3$：

$$
0\to3\to6\to1\to4\to7\to2\to5\to0
$$

全部 8 个人都接到了球。你给出了关键观察：

> **8 和 3 互质。**

### 2.3 为什么互质是充要条件？

球第一次回到起点，意味着存在**最小正整数** $t$ 满足：

$$
tK\bmod N=0
$$

也就是：

$$
\boxed{N\mid tK}
$$

设：

$$
d=\gcd(N,K),\quad N=dN',\quad K=dK'
$$

那么 $\gcd(N',K')=1$，而

$$
N\mid tK
\Longleftrightarrow dN'\mid tdK'
\Longleftrightarrow N'\mid tK'
$$

因为 $N'$ 与 $K'$ 互质，所以 $N'\mid t$。因此第一次回到起点的步数是：

$$
\boxed{t_{\min}=\frac{N}{\gcd(N,K)}}
$$

在这之前不会提前重复其他位置：若第 $i$ 步和第 $j$ 步（$0\le i<j<t_{\min}$）的位置相同，就会有 $(j-i)K\bmod N=0$，与最小周期的定义矛盾。

所以不同位置的数量正好是：

$$
\boxed{\text{访问的不同人数}=\frac{N}{\gcd(N,K)}}
$$

只有这一数量等于 $N$，才能传遍全体：

$$
\frac{N}{\gcd(N,K)}=N
\quad\Longleftrightarrow\quad
\boxed{\gcd(N,K)=1}
$$

**这就是本题需要判断的条件。**

### 2.4 为什么从大到小枚举？

题目求最大的合法步长，因此：

```cpp
for (int k = n / 2; k >= 1; k--) {
    if (gcd(n, k) == 1) {
        cout << k << '\n';
        break;
    }
}
```

`break` 可以直接结束循环，是因为当前 `k` 是从大到小遇到的第一个合法候选，后面的 `k` 只会更小。

### 2.5 用于复习的完整程序

> 以下是根据今天的结论整理的**参考实现**，不代表今天已有实际提交记录。使用自写的 GCD，不要求 C++17。

```cpp
#include <iostream>
using namespace std;

// 辗转相除法
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int main() {
    int n;
    cin >> n;

    // 最大合法 K
    for (int k = n / 2; k >= 1; k--) {
        if (gcd(n, k) == 1) {
            cout << k << '\n';
            break;
        }
    }

    return 0;
}
```

每次 GCD 的时间复杂度为 $O(\log N)$，最多测试 $O(N)$ 个候选步长，所以总时间复杂度上界为：

$$
\boxed{O(N\log N)}
$$

循环版 GCD 的额外空间为 $O(1)$。

几个例子：

| $N$ | 最大合法 $K$ | 原因 |
|---:|---:|---|
| 8 | 3 | $\gcd(8,3)=1$ |
| 9 | 4 | $\gcd(9,4)=1$ |
| 12 | 5 | $\gcd(12,5)=1$ |

## 3. `%` 与环形数组：同一原理的两个应用

### 3.1 回忆之前学的环形遍历

```cpp
i = (i + 1) % n;
```

若 $n=8$，从 0 开始：

$$
0\to1\to2\to3\to4\to5\to6\to7\to0
$$

下标始终保持在 `0` 到 `n-1`。

将步长 1 改成任意整数 $K$：

```cpp
i = (i + k) % n;
```

下标依然不会越界，但不一定能**走遍所有位置**。是否遍历全部的判据是：

$$
\boxed{\gcd(N,K)=1}
$$

### 3.2 取模保证绕圈，互质保证走遍整圈

| 总位置数 $N$ | 步长 $K$ | $\gcd(N,K)$ | 访问的不同位置数 | 结果 |
|---:|---:|---:|---:|---|
| 8 | 1 | 1 | $8/1=8$ | 全部 |
| 8 | 2 | 2 | $8/2=4$ | 一半 |
| 8 | 3 | 1 | $8/1=8$ | 全部 |
| 8 | 4 | 4 | $8/4=2$ | 四分之一 |
| 12 | 8 | 4 | $12/4=3$ | 只有三个位置 |

**特别注意**：即使循环写了 `for (int count=0; count<n; count++)`，如果 $N$ 和 $K$ 不互质，也会重复访问部分下标；循环次数等于 `n` 不代表不同位置的数量就是 `n`。

例：$N=10,\ K=3$。

```cpp
int i = 0;
for (int count = 0; count < 10; count++) {
    cout << i << ' ';
    i = (i + 3) % 10;
}
```

输出：

```text
0 3 6 9 2 5 8 1 4 7
```

由于 $\gcd(10,3)=1$，恰好遍历了全部 10 个下标。

### 3.3 一句话辨别这两个概念

- **`% N` 解决：位置超出末端后如何回到开头？**
- **`gcd(N,K)==1` 解决：每次固定走 $K$ 格，会不会提前返回起点？**

## 4. 辗转相除法（欧几里得算法）

### 4.1 什么是最大公约数？

最大公约数记作 $\gcd(a,b)$。

例如，12 的因数有 $1,2,3,4,6,12$，8 的因数有 $1,2,4,8$，所以：

$$
\boxed{\gcd(12,8)=4}
$$

两个正整数互质，当且仅当：

$$
\boxed{\gcd(a,b)=1}
$$

### 4.2 核心公式

$$
\boxed{\gcd(a,b)=\gcd(b,a\bmod b)}\qquad(b\ne0)
$$

终止条件：

$$
\boxed{\gcd(a,0)=a}\qquad(a>0)
$$

例：求 $\gcd(48,18)$

$$
\begin{aligned}
48&=18\times2+12,\\
18&=12\times1+6,\\
12&=6\times2+0.
\end{aligned}
$$

所以：

$$
\begin{aligned}
\gcd(48,18)
&=\gcd(18,12)\\
&=\gcd(12,6)\\
&=\gcd(6,0)\\
&=\boxed{6}.
\end{aligned}
$$

### 4.3 公式为什么成立？

设 $a,b$ 是正整数，带余除法告诉我们：

$$
a=qb+r,\qquad r=a-qb
$$

若 $d$ 同时整除 $a,b$，那么也整除 $r=a-qb$。

反过来，若 $d$ 同时整除 $b,r$，那么也整除 $a=qb+r$。

也就是说，$(a,b)$ 和 $(b,r)$ 的公因数集合相同，因此最大公约数也相同：

$$
\boxed{\gcd(a,b)=\gcd(b,r)}
$$

其中 $r=a\bmod b$。

因为每次新的余数满足 $0\le r<b$，数不断变小，最后一定能得到余数 0。

### 4.4 C++：循环版

```cpp
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b; // 当前余数
        a = b;         // 旧的 b 变成新的 a
        b = r;         // 余数变成新的 b
    }
    return a;
}
```

这三行：

```cpp
int r = a % b;
a = b;
b = r;
```

实际上是在实现数学中的状态变换：

$$
(a,b)\longrightarrow(b,a\bmod b)
$$

先用变量 `r` 暂存余数，是为了避免赋值覆盖旧数据。

### 4.5 C++：递归版

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

`gcd(48,18)` 向下递归：

```text
gcd(48,18)
  -> gcd(18,12)
    -> gcd(12,6)
      -> gcd(6,0)
```

最底层 `gcd(6,0)` 返回 6，上面三层也依次返回 6。

这段代码之所以需要 `return gcd(...)`，与今天下一个主题直接有关。

## 5. `void` 递归与有返回值的递归：真正的区别

### 5.1 今天提出的疑问

> 为什么 `void dfs(...)` 往往直接写 `dfs(a,b);`，而求 GCD 的 `int gcd(...)` 要写 `return gcd(a,b);`？

最重要的答案：

**调用下一层函数**和**把下一层的计算结果返回给上一层**是两个不同动作。

- `dfs(x);` 只是调用它，若有返回值则忽略。
- `return dfs(x);` 会调用它，然后把它的返回值**作为当前函数的返回值**交出去。

### 5.2 `void` 递归：负责执行动作

```cpp
void printDown(int n) {
    if (n == 0) return;  // 终止本层函数，不返回数字

    cout << n << ' ';
    printDown(n - 1);
}
```

调用 `printDown(3);`，打印：

```text
3 2 1
```

函数只负责**打印**，不需要返回一个 `int` 答案。

注意 `void` 函数可以写 `return;`，但不能写 `return 6;`。

### 5.3 `int` 递归：求值之后要传回去

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

这一行：

```cpp
return gcd(b, a % b);
```

等价于：

```cpp
int result = gcd(b, a % b);
return result;
```

每一层都会把下一层求出的答案继续返回，所以最初的调用者才能得到 GCD。

错误示例：

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    gcd(b, a % b); // 调用了下一层，却没有返回它的结果
}
```

对于 `b != 0` 的执行路径，这个 `int` 函数最终没有返回值，会造成 **未定义行为**。下一层已经算出正确答案，并不代表外层也返回了正确答案。

### 5.4 并非所有 `int` 递归都写 `return f(...)`

例如递归求和：

```cpp
int sum(int n) {
    if (n == 0) return 0;
    return n + sum(n - 1);
}
```

递推关系：

$$
S(n)=
\begin{cases}
0,&n=0,\\
n+S(n-1),&n>0.
\end{cases}
$$

例如：

$$
\begin{aligned}
S(3)&=3+S(2)\\
&=3+2+S(1)\\
&=3+2+1+S(0)\\
&=\boxed{6}.
\end{aligned}
$$

这里需要对下一层结果**再加上当前的 `n`**，因此不是简单的 `return sum(n - 1)`。

也可以先存储两条分支的答案：

```cpp
int fib(int n) {
    if (n <= 1) return n;

    int a = fib(n - 1);
    int b = fib(n - 2);

    return a + b;
}
```

这种形式说明：递归函数可以拿到多个子问题的返回值，再合并成自己的答案。

| 代码 | 实际作用 |
|---|---|
| `dfs(x);` | 调用函数，不使用返回值 |
| `return;` | 结束当前 `void` 函数 |
| `return dfs(x);` | 直接返回下一层的答案 |
| `return n + dfs(x);` | 计算后返回 |
| `int result = dfs(x);` | 保存下一层的答案供后续使用 |

### 5.5 与之前的「装载问题」联系

装载问题中，之前写过如下风格的 DFS：

```cpp
int best = 0; // 共享变量：记录最优装载重量

void dfs(int id, int sum) {
    if (sum > c1) return;

    if (id == n) {
        if (sum > best) best = sum;
        return;
    }

    dfs(id + 1, sum + w[id]); // 选择装进第一艘船
    dfs(id + 1, sum);         // 选择不装进第一艘船
}
```

这里 `dfs` 是 `void`，因为**答案被写进全局变量 `best`**；函数本身不必返回它。

如果改成由递归函数**直接返回最优重量**，则可以写为：

```cpp
#include <algorithm> // max

int dfs(int id, int sum) {
    if (sum > c1) return -1; // 重量非负时，-1 表示无效方案
    if (id == n) return sum;

    int take = dfs(id + 1, sum + w[id]);
    int skip = dfs(id + 1, sum);

    return max(take, skip);
}
```

使用方式变成：

```cpp
int best = dfs(0, 0);
```

**本质区别**：

1. `void dfs`：在搜索中**修改外部共享状态**，答案留在外部。
2. `int dfs`：每个子问题**返回答案**，由上一层合并。

这是后续学习**记忆化搜索、动态规划**的重要铺垫。

## 6. 今日易错点（概念性提醒）

> 今天没有出现新的 OJ 判题错误或你提交的 C++ 代码错误。以下仅总结讨论中可能遇到的概念陷阱，**不是实际报错记录**。

1. **误认为 `% N` 一定能遍历所有下标**：它只保证下标保持在环内；是否遍历全部取决于 $\gcd(N,K)$。
2. **只记忆“互质就行”，不理解证明**：可以从 $N\mid tK$ 推导 $t_{\min}=N/\gcd(N,K)$。
3. **在 `int` 递归中漏掉 `return`**：`gcd(b,a%b);` 不能替代 `return gcd(b,a%b);`。
4. **以为有返回值的递归必须直接返回下一层**：还可能需要 `return n+f(...)` 或将多个子问题结果合并。
5. **混淆输出与返回值**：`cout` 输出到屏幕，不等于当前函数通过 `return` 返回整数。
6. **辗转相除更新参数时覆盖旧值**：先算 `r=a%b`，再执行 `a=b; b=r;`。

## 7. 小练习：检验是否真正理解

### 练习 A：12 个人，每次跳 8 格

$$
\gcd(12,8)=4,\qquad
\frac{12}{4}=\boxed{3}
$$

球的传递顺序：

$$
0\to8\to4\to0
$$

答案：第一次回到起点之前，有 **3 个不同的人**接到球。

### 练习 B：求 $\gcd(35,12)$

$$
\begin{aligned}
35&=12\times2+11,\\
12&=11\times1+1,\\
11&=1\times11+0.
\end{aligned}
$$

因此：

$$
\boxed{\gcd(35,12)=1}
$$

35 和 12 互质。

### 练习 C：两个 `f(3)` 的区别

```cpp
void f(int n) {
    if (n == 0) return;
    cout << n << ' ';
    f(n - 1);
}
```

它会**输出** `3 2 1`，但没有返回一个数值。

```cpp
int f(int n) {
    if (n == 0) return 0;
    return n + f(n - 1);
}
```

它会**返回**：

$$
3+2+1+0=\boxed{6}
$$

两个函数分别展示了“执行任务”和“计算并传回答案”。
